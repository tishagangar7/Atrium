**Decisions and why:**
- `BeliefView.world` stays a dict (serialized `WorldState` + `nodes/horizon/grid/targets` + derived fields) so the
  existing agents' prompts and tools work unchanged; `evaluate_plan` rebuilds a masked `WorldState` from it.
- Plan timing (waits) is fixed at expansion time and legs execute by schedule; with one committed plan at a time plus
  locked legs this is exactly §5.7's deterministic waits without re-planning inside the engine.
- Closures block entry, not travel in progress (D-10): a traverse leg whose road is closed at entry is skipped
  (`task.skipped_unsafe`, reason `ROAD_CLOSED`) and the vehicle holds — no automatic rerouting.
- Crew safety guard (§5.5): a contain leg whose target reached intensity 4 at start is skipped, crew holds.
- Unload never exceeds shelter capacity at execution (the remainder stays aboard, logged) so §5.6 holds even if a
  stale plan is executed.
- `evaluate_plan` skips per-step invariant checks for speed; execution (`service.step`) checks them every step.

**Gotchas / traps:**
- **Tuning finding (for §5.13 / G2):** with the PRD's proposed `k = 0.06` the fire reaches ~54 of 60 cells by step 60
  regardless of one crew's containment; the §5.12 fire-extent floor is 30. Realized exposure with no plan is 2270 vs.
  the 1200 floor. Tune `k`, fuel defaults or targets in the JSON (record in `scenarios/CHANGELOG.md`); do not touch rules.
- `plans.expand` processes assignments per resource in list order, interleaving resources by effective start; an
  assignment with `start_step=None` follows its resource's previous one (a `load` before its `drive` is `WRONG_LOCATION`).
- `service.step(n)` stops *before* a step with a scheduled event after applying it (`paused=True`, version +1); the
  controller must renegotiate and call `step` again to continue from that step.
- `check.sh` runs the frontend typecheck now that `frontend/package.json` is on `main`: run `npm ci` in `frontend/`
  once per fresh worktree or the gate fails for a reason unrelated to backend work.
- `app.negotiation` is not on `main`; sim tests must not import it (they build `Assignment`s from `plan_timing`).
